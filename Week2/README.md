# 📖 What is LWC?
Lightning Web Components (LWC) are modern Salesforce UI components used to build fast, reusable, and interactive user interfaces.

LWC uses HTML, JavaScript, and Metadata files.

---

# 📖 Why Salesforce Uses LWC
Salesforce uses LWC to create modern, reusable, and efficient UI components with better performance and maintainability.
