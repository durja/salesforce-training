# 🚀 Salesforce Summer Program – Day 12 DX Workflow

---

# 📖 What is Salesforce DX?
Salesforce DX is a modern development workflow used for source-driven development, team collaboration, and version control in Salesforce projects.

It helps developers manage code efficiently using GitHub, CLI, and VS Code.

---

# 💻 Why CLI Matters
Salesforce CLI helps developers work faster using terminal commands instead of only browser clicks.

It improves productivity, automation, and deployment workflow.

---

# 🌐 Why GitHub Matters
GitHub helps teams store, manage, track, and collaborate on project code using version control.

It also helps maintain backup and rollback support.

---

# 👥 Team Collaboration Problems

Without version control and deployment workflow:
- Code conflicts may happen
- Developers may overwrite each other’s work
- Bugs may enter production
- Rollback becomes difficult
- Project management becomes confusing

---

# 🏗️ Enterprise Workflow Discussion

Enterprise software development requires:
- Team collaboration
- Testing
- Deployment workflow
- Rollback capability
- Version control
- Reliable development process

Unlike college assignments, enterprise projects involve large teams, real users, and continuous updates.

---

# 💭 Reflection

Salesforce workflow showed how professional software engineering depends on collaboration, version control, testing, deployment, and structured development practices.
