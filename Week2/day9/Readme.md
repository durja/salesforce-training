# 🔄 Component Communication

Components communicate to share data and update information between different parts of the application.

## Parent-Child Communication
Used when one component sends data directly to another component.

## Events
Used to notify other components when an action happens.

---

# 🏫 Dashboard Design – College Management System

## Student Dashboard
- Student Info Component
- Attendance Component
- Course Component
- Notification Component

## Faculty Dashboard
- Faculty Info Component
- Student Attendance Component
- Course Management Component

## Admin Dashboard
- Student Records Component
- Faculty Management Component
- Reports Component

---

# 🔗 Component Interaction

- Attendance Component communicates with Student Info Component
- Course Component updates Notification Component
- Admin Dashboard interacts with Student and Faculty Components

# 🔄 Data Flow Explanation – Student Registration

UI Form →  
Validation checks data →  
Flow sends confirmation →  
Apex handles business logic →  
Database stores records →  
Notification sent to student

# ⚡ Aura vs LWC

## Aura
- Older Salesforce UI framework
- More complex and slower

## LWC
- Modern component-based framework
- Faster and better performance
- Reusable and easier to maintain

# 💭 Reflection

Enterprise applications use modular architecture because it improves scalability, maintenance, reusability, and performance.

It also helps developers manage large systems more efficiently.
